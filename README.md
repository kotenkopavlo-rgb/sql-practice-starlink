# SQL Practice – Starlink Analytics

## About

This repository contains SQL practice tasks completed as part of my transition from Game QA Engineer to Data Analyst.

The goal of this project is to demonstrate practical SQL skills through realistic business scenarios.

## Skills Demonstrated

- Writing analytical SQL queries
- Data aggregation
- Multi-table joins
- Common Table Expressions (CTE)
- Window Functions
- Correlated Subqueries
- Handling NULL values
- Revenue calculations
- Customer support analytics

## Database

The project uses three tables:

- starlink_customers
- subscriptions
- support_tickets

## Database Schema

- starlink_customers
- subscriptions
- support_tickets

## How to Run

1. Execute `schema.sql`.
2. Import SQL files from the `data/` folder:
   - `starlink_customers.sql`
   - `subscriptions.sql`
   - `support_tickets.sql`
3. Run any SQL script from the `tasks/` folder.
